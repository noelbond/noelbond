## Featured Work

### Victory Garden

**Rails-centered greenhouse automation and distributed control system**

Victory Garden is a commissioned software development and independent engineering project.

The system uses Rails as the control plane for configuration, telemetry, device state, and operator workflows while Python handles automatic irrigation decisions and Raspberry Pi Pico firmware manages sensing and physical actuation.

**Technologies:** Ruby on Rails, PostgreSQL, Python, Solid Queue, MQTT, Mosquitto, Raspberry Pi, Pico W, C, Linux

Engineering areas include:

- asynchronous command and result correlation
- device provisioning and configuration state
- telemetry ingestion and historical trends
- retries, timeouts, stale-data protection, and idempotency
- fail-safe actuator behavior
- automated Rails, Python, and firmware testing
- Raspberry Pi/Linux deployment

[View Victory Garden](https://github.com/noelbond/victory_garden)
